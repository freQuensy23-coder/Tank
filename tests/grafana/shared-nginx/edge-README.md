# Shared nginx edge fixture

Run `python3 tests/grafana/shared-nginx/edge-run.py` with local Docker and Compose 2.24.4 or newer. The disposable internal network has no published ports. Building the nginx/Certbot fixture may require access to image and package registries.

The fixture runs the host setup against real nginx and Certbot. Pebble validates HTTP-01 through the existing default webroot on first issue and the new site on renewal. A systemctl stand-in signals real nginx; the fixture mirrors the system deploy hook and invokes native renew directly, not a systemd timer. It checks the served certificate on both address families, default and named neighbors, repeat setup and downgrade/restore with the site left enabled. The isolated namespace binds Grafana to the host address and port from each real rendered Compose model instead of publishing on the test machine. Real Grafana and PostgreSQL verify HTTPS Viewer login, secure cookies, anonymous and admin denial, dashboards and panel queries. No public CA, live host reload or browser rendering is involved.
