# Code vs plan — full check, 20 Oct 2026

This is a read-only check of the current working tree against the PRD, HLD and TDD, including the 19 Oct decisions: Tank trusts the semantics registry, and the agent owns claims, stages, certainty and wording. Corner cases are left out. This file replaces `2026-10-19_full.md`.

## Fixed since 19 Oct

- **Agent judgment:** certainty is no longer raised or lowered by code, M is not recomputed, the keyword stage ladder and GitHub→BUILT on the event ladder are gone, and there is no card linter. Claims, `verified`, stages and certainty are stored as the agent gives them. Only V3 entity resolution is done by Tank.
- **Semantics:** the registry is trusted, with no self-tests and no semantic confidence. A1 = `dc.class == LOW → WAIT`.
- **Card gate:**
  - STALE events send nothing, including EXIT, FATAL and expiry updates.
  - Rate-limited updates are refused, no longer held and merged.
- **Action matrix:** WATCH_ANCHOR_LOST and WATCH_SELL_DOWNGRADE now match the §6.6 downgrades, and the START guards match FR-T-12.
- **Post-turn playbook audit:** removed. A narrower check is left (B4).
- **Storage and checks:** `mkt.trades` dropped; `ops.budget_state` retired. Test vectors T1–T9 pass.
