- **Docker Compose** (`tank`, `openma`, `postgres`, KVM, Docker secrets, volumes): matches. OpenMA is built from a patched checkout and the sandbox image is local, not the pinned release image and `openma/sandbox-base` of HLD §8.

- **Agent sandbox** (`tank-analysis` unrestricted, `tank-replay` database only, `tank_agent` read-only): matches; the sandbox also gets `TANK_JEV_PROVIDER`.
- **18 tools, built-in tools, harness pi, skills**: matches.
- **web_search on DuckDuckGo**: matches.
- **No token or spending limits**: matches.
- **Jev via OpenRouter**: model and key match; the endpoint is `/api/v1/systemone`, not `/api/v1/chat/completions` (N4).
