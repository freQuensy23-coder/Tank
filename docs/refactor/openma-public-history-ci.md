## Retained mappings and absence

The pnpm `packages`, `snapshots` and `importers` mappings are actual externally keyed dependency indexes; per-context edge dictionaries index dependency names and prevent conflicting duplicate edges. They are not substitutes for named manifest records. `None` on a projected pnpm dependency section means that section was not declared; `None` on os/cpu/libc means pnpm imposes no such platform restriction. Missing required root declarations still refuse. Omitted optional edges carry one of the explicit unrequested-feature or unsupported-platform reasons in the manifest. Unknown unused upstream metadata is projected away at the lock boundary without rewriting the lock or package sources. Archive bytes remain opaque until verified extraction; output/result reports use named records and JSON serialization only at their actual wire boundaries.
